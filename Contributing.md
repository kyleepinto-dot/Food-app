# Contributing

Thanks for your interest in improving Food-app.

## Getting started

1. Fork the repository and clone your fork locally.
2. Create and activate a virtual environment.
3. Install the project dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Run the app locally to verify your changes:

   ```bash
   python MAIN.PY
   ```

## Guidelines

- Keep changes focused and easy to review.
- Update documentation when behavior or setup changes.
- If you add new dependencies, include them in requirements.txt.
- Test the app manually before opening a pull request.

## Pull request checklist

- Describe what changed and why.
- Include any relevant screenshots or notes.
- Make sure the app still starts successfully.
